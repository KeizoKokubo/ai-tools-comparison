# AIツール比較（公開版）

主要AIツールを、人物キャラクターになぞらえて紹介する比較ガイドの公開リポジトリです。

- **Webサイト**: このリポジトリの GitHub Pages で紹介記事ページ（`index.html`）を公開しています
- **データ**: `data/tools.json` — 公開用に整形した比較データ（ツール名、分類、キャラクター、料金要約、プラットフォーム、強み・弱み、注意点、出典リンク、確認日、編集部評価スコア）

## データについて

- 料金・モデル等の情報は、各社の公式ページ等の公開情報に基づきます（出典はデータ内の各ツールに記載）
- 確認日: 2026-11-05。AIツールの料金・モデルは短期間で変更されることが多いため、意思決定の前に公式ページで最新情報をご確認ください
- スコア（6軸・1〜5）は調査に基づく編集部評価であり、公式スペックではありません
- Sora（OpenAI）は提供終了のため、歴史的参照として掲載しています

作業用リポジトリ（非公開）で調査・編集を行い、公開可能な最小限のデータセットだけをこのリポジトリに反映しています。
